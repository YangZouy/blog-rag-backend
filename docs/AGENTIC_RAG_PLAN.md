# Agentic RAG 分模块实施计划

目标是保留现有 hybrid retrieval、RRF、ONNX rerank、SSE 和检索评测，
在外围增加受控编排能力。每个模块独立测试、独立提交，线上默认保持稳定路径。

1. 多轮指代改写：仅在检测到指代且存在历史时调用轻量模型；独立问题直接检索；缓存键包含历史。
2. 复杂问题分解：识别多个目标，最多 4 个子问题，并行检索、去重和重排。
3. 证据充分性：输出充分、部分充分、不足三类，约束回答边界并校验来源归因。
4. 有界补救：证据不足时只执行一次白名单动作，第二轮仍不足立即终止。
5. 运行轨迹：记录规划、检索、评估、补救和最终决策；通过 SSE/前端演示开关展示。
6. 评测集和指标：补充多轮、跨文档、部分/无答案、实时、注入和越权样本及预期行为。
7. 本地/线上策略：本地用于 Agentic 基准和录制，线上通过配置关闭规划或使用轻量策略。
